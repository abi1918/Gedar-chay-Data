# Gedar-chay-Data
Benchmarking Objective Functions for Hydrological Model Calibration: A Multi Regime Assessment in a Snow Fed Agricultural Watershed
Model calibration draws on daily precipitation and temperature records from the Mahabad synoptic station (Iran Meteorological Organization) and streamflow observations from the Naqadeh and Bahramlou gauging stations (West Azerbaijan Regional Water Authority), spanning 1985–2016 across the snow-fed, semi-arid Gedarchay River Basin (Lake Urmia drainage, northwestern Iran). The watershed was delineated in ArcSWAT2012/ArcGIS 10.7 into 88 sub-watersheds and 1,616 Hydrological Response Units, using land use, soil (FAO/UNESCO HWSD), and slope data. Calibration and uncertainty analysis were performed in SWAT-CUP Premium using the SWAT Parameter Estimator (SPE) module with the SUFI-2 algorithm (2,500 iterations per scenario) across nine scenarios: eight single-objective functions (R², NS, RSR, MNS, SSQR, KGE, bR², PBIAS) and one weighted multi-objective function combining R², NS, and PBIAS. Calibration and validation periods were assigned via an alternating-block design (1988–1992, 1996–2000, 2004–2008, 2012–2016 for calibration; intervening years for validation), spanning both wet and dry years per the Standard Precipitation Index to ensure robust performance assessment across high-, median-, and low-flow regimes, evaluated using P-factor/R-factor uncertainty statistics and flow-duration-curve segmentation (Q10/Q50/Q80/Q90). All spatial and temporal input data, ArcSWAT project files, and the SWAT2012 database are openly available at the Gedar-chay-Data GitHub repository.
